**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. This is SuperMedo's 0.3.6 plus this fork's changes: everything in 0.3.6.29 plus the list below. The two separate performance test builds (0.3.6.27-perf1 and 0.3.6.29-perf2) are folded into this release; there are no separate perf builds any more.

**Installing:** unpack into a new folder and start `Uncharted.exe`. Your launcher settings carry over, but saves live in each install's own `user\savedata` folder: copy that folder over from your previous install, or set **Saves folder** in the launcher to it. From this version on the launcher updates itself (see below).

## Shader preparation: no more shader stutter
- **The first start of each game builds its shaders before you play**, on a *Preparing shaders* page, instead of the first time each effect appears on screen. The lists of what to build come from playing through all three games, on the EU and US versions. The game waits behind the page, and later starts skip it.
- **How long:** measured on one PC (RTX 5080, 16-thread CPU) with an empty shader cache: about 36 s for Uncharted 3, and with a simulated older 4-core processor about 70 s for Uncharted 3, 24 s for Uncharted 2 and 11 s for Uncharted 1. Your times will differ. Most of it is your graphics driver building pipelines; with a driver cache already warm it is much shorter.
- **The shader cache's format changed**, so the first start after updating rebuilds it once (the preparation page does that).
- Launcher: **Shader preparation** section (before play, in the background, or off; Prepare now; status). If a large shader cache ever causes problems, clear it there and turn preparation off.
- Tested on NVIDIA graphics. AMD and Intel have not been tested yet.
- How it was built and what was tried: `docs/SHADER_PREPARATION.md`.

## Faster when the processor is the limit
The port turns the game's PS4 GPU commands into Vulkan on three threads (command processor, draw recorder, Vulkan recorder). This release takes work off them and cuts the waiting between them, work that was in the two perf test builds until now.

**About +22% where the processor sets the pace, plus about +6% (Uncharted 2 and 3) to +13% (older processor) on top; little or nothing where the graphics card is the limit.** Measured on one PC: your numbers will differ.

First round (as in 0.3.6.27-perf1), the same build without and with the work:

| DLSS Performance, 3440 × 1440 output | Uncharted 1 | Uncharted 2 | Uncharted 3 |
|---|---|---|---|
| Processor sets the pace | 159 → 194 FPS (+22%) | 178 → 218 FPS (+23%) | 115 → 140 FPS (+22%) |
| Native 3440 × 1440 | 133 → 138 FPS (+4%) | 125 → 138 FPS (+10%) | 116 → 131 FPS (+13%) |
| Older 4-core CPU simulated (8 threads at 60% clock) | | | 62 → 77 FPS (+24%) |

Second round (as in 0.3.6.29-perf2), on top of the first, DLSS Performance: Uncharted 3 Cartagena square 146 → 156 FPS (+7%), the simulated older CPU 77 → 87 FPS (+13%), Uncharted 2 museum 150 → 159 FPS (+6%), Uncharted 1 jungle about +2% (within the noise there).

Measured on an RTX 5080 with a 16-thread CPU, EU versions, frame generation off, uncapped, the same saved spot each run, builds taking turns over 2 rounds. With a frame rate cap your PC already holds there is no gain, though frame times are steadier (Uncharted 3 at 1080p: the slowest 1% of frames 9.3 ms instead of 12.6 ms). The simulated older processor is a fast one slowed down; real older processors can do worse.

- **What changed:** the games' constant data is copied on a thread of its own; neighbouring read-only buffers are bound together; fences go to the Vulkan recorder in batches instead of one hand-off each; the draw recorder no longer waits for the Vulkan recorder before plain submissions; memory the GPU is about to write is tracked with a fast ordered list; game writes to memory the GPU also uses are read back on the writing thread (che2281337's idea); end-of-shader markers ride on work already queued (che2281337).
- **New in this release: a faster lock in the shader pipeline cache.** The cache's lock made the GPU thread and the shader-preparation workers queue behind each other on every shader lookup. A Windows slim reader/writer lock now takes it. Uncharted 3's crowded market, same PC, uncapped: about +7% on average and **+14% in the worst 5-second stretch**; no measurable change on the simulated older processor. `BB_SRW_LOCKS=0` turns it off.
- Developers: how each part works, the measurements and every switch are in `docs/PERF_BUILD.md`.

## Fixes
- **Uncharted 2, chapter 21 (convoy): Elena's truck no longer sinks into the snow** for half a second after the enemy truck rams it. A bug in the game itself: when the bump animation starts, the game never fills in one of its settings, and whatever was left in memory there could switch the truck's rail animation to follow the truck's own last position, so the bump's movement added up frame after frame. On the PS4 that leftover value happened to be harmless. Fixed for the EU and US versions (`BB_CONVOY_SINK=0` turns the fix off). The convoy's speed controller also counts at least one game clock tick per frame (from drakolordx7).
- **Uncharted 1, jet ski: floating barrels no longer freeze in mid-air above 60 FPS.** The physics engine holds still any body that moves slower than a fixed amount per step, and at high frame rates each step is smaller, so slow-drifting barrels stopped. That threshold now scales with the step.
- **NVIDIA: no more "graphics device lost" crashes in Uncharted 1 and 2 above about 55 FPS.** Compute work in large groups runs as smaller groups (Umar's fix).
- **Skip the friends' stats notice** (launcher option, on by default): Continue and New Game no longer stop on the notice that friends' stats are not available. Nothing goes online.
- Button prompts are drawn ahead, so the first prompt no longer stalls a frame.

## Launcher
- **Updates:** the launcher looks for a new version of this fork when it starts and offers to install it. Saves, settings, the shader cache and art are never replaced. *Look for a new version when the launcher starts* turns the check off.
- The texture (de)tiling pipelines the games need are built ahead and remembered.

## From 0.3.6.29
- **Uncharted 1 and 2: no more stop on the game's own check `pAction != NULL`** at high frame rates (room for 256 moves instead of 64).
- **Video memory give-back (cards with 4 to 6 GB): safer** — unmapped only after the graphics card has finished with it, watched before it is handed back.
