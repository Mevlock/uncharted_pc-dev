**Pre-release: needs testing.** Uncharted 1 gets the same high-frame-rate crash fix as Uncharted 2, and the video memory give-back for 4 to 6 GB cards is made safer. Tested on the EU and US versions.

**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. This is SuperMedo's 0.3.6 plus this fork's changes; everything in 0.3.6.28 plus the list below.

**Installing:** unpack into a new folder and start `Uncharted.exe`. Your launcher settings carry over, but saves live in each install's own `user\savedata` folder: copy that folder over from your previous install, or set **Saves folder** in the launcher to it. The first start of each game compiles its shaders again (some stutter for the first minutes).

## New in 0.3.6.29 (pre-release)
- **Uncharted 1: the same fix as Uncharted 2 in 0.3.6.28** for the game's list of Drake's current moves (room for 64, now 256). Uncharted 1 has the same list and the same habit of not letting go of a move when two take turns every frame, so at high frame rates it could fill up the same way. EU, US and EU/Russian versions.
- **Video memory give-back (cards with 4 to 6 GB, where it is active): safer.**
  - Memory handed back is now unmapped only after the graphics card has finished every frame that might still read it. Before, it could be unmapped while frames already sent were still using it, which can stop the graphics card.
  - Memory is watched for a few seconds before it is handed back: if the game's shaders still read it, it is kept.
  - A range the game uses again right after it was handed back keeps its own memory instead of getting other memory while frames already sent still read it.
  - On cards with more video memory, where give-back never starts, nothing changes.

## From 0.3.6.28 (pre-release)
- **Uncharted 2: no more stop on the game's own check `pAction != NULL`** at high frame rates (room for 256 moves instead of 64).

Older changes: see the 0.3.6.28 and 0.3.6.27 release notes.
