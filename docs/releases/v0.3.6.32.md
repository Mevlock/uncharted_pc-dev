**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. Everything in 0.3.6.31 plus the changes below.

**Installing:** the launcher of 0.3.6.30 or 0.3.6.31 offers this update itself; or unpack into a new folder and start `Uncharted.exe`.

## Fixed
- **The shader cache stays with each install.** If you had set a **Saves folder** in the launcher, every version you unpacked used the shader cache of the install that folder belonged to. Versions then kept rebuilding or pruning each other's caches, which meant long first starts and stutter in places that should have been smooth. Saves, trophies and settings still follow your Saves folder; the shader cache now always lives in the install's own `user\cache` folder. If you use a Saves folder, this version shows the shader preparation page once; with the default setting nothing changes.
- **Uncharted 1 at high frame rates:** objects, debris and bodies come to rest after the same time at any frame rate. Above 60 FPS they settled too early (at 144 FPS in about 40% of the time), and the game's slow-down of moving objects was applied per frame instead of per second.
- **Uncharted 1:** one more shader variant and two pipelines are prepared ahead, so a short hitch on first play near the start of chapter 4 is gone.

## For bug reports
The first lines of `last_run.log` now also show where your saves and your shader cache are.
