**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. This is SuperMedo's 0.3.6 plus this fork's changes; everything in 0.3.6.10 plus the list below.

**Installing:** unpack into a new folder and start `Uncharted.exe`. Your launcher settings carry over, but saves live in each install's own `user\savedata` folder: copy that folder over from your previous install, or set **Saves folder** in the launcher to it.

## New in 0.3.6.11
- **Fewer crashes with "execute access to 0000000000000000" (exit code 3)**, the most reported crash, mostly in Uncharted 1, and **Uncharted 1's crash at 0x63f5d0** (on Intel 12th gen and later). Both came from the same place: while Windows handles a memory fault, it overwrites values some of the game's functions keep just below the stack, and the game then carried on with garbage. Those functions now move the stack out of the way around the stores that can fault, in all three games, EU (CUSA02343) and US (CUSA02320). From [d4rksp4rt4n's PR #403](https://github.com/Supermedo/uncharted_pc/pull/403) (ported from the Bloodborne port), with the cause pinned down in [drakolordx7's PR #396](https://github.com/Supermedo/uncharted_pc/pull/396). No FPS cost. `BB_RED_ZONE=0` in the launcher's extra environment turns it off.
- **Uncharted 3's brightness no longer pumps up and down, and Nate's weapon no longer draws black.** The auto-exposure value the GPU works out each frame never reached the game. From [G3545's PR #449](https://github.com/Supermedo/uncharted_pc/pull/449). Treasure glints in Uncharted 3 look like proper sparkles again rather than a small white dot, likely from the same fix. No FPS cost.

## Known issues
- Uncharted 3: single-frame lighting flashes are rarer since 0.3.6.7 but may not be gone entirely.
- Uncharted 1 and 2 with Quality, Balanced or Performance, and Uncharted 2 at native resolution, work in the opening areas but haven't had a full playthrough (cutscene videos, HUD, menus).
- Ultrawide: short scripted scenes can still switch to 16:9 by mistake; **Always fill** avoids it.
- Rarely, the game freezes while exiting; if it happens, end `bb-probe.exe` in Task Manager.
- Fast mouse aiming covers the EU (CUSA02343) and US (CUSA02320) versions; other versions keep stick-style aiming.
- DLSS Frame Generation goes up to 4×.
