**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. This is SuperMedo's 0.3.6 plus this fork's changes; everything in 0.3.6.11 plus the list below.

**Installing:** unpack into a new folder and start `Uncharted.exe`. Your launcher settings carry over, but saves live in each install's own `user\savedata` folder: copy that folder over from your previous install, or set **Saves folder** in the launcher to it.

## New in 0.3.6.12
- **The frame rate drop and stutter in 0.3.6.11 are fixed.** 0.3.6.11's fix for Uncharted 3's pumping brightness copied every tiny buffer the GPU wrote back to the game, several times a frame, waiting for the GPU each time: about 10% slower in busy scenes (Cartagena square: 80 FPS against 89 in 0.3.6.10), and dips like 165 to 130 FPS at high frame rates. It now copies only the one value the game needs (Uncharted 3's auto-exposure, 16 bytes) and doesn't wait for it. Back to 0.3.6.10's speed, and the brightness fix stays. This also removes a likely cause of the crashes some players saw after updating to 0.3.6.11; if you still crash, please send `user\last_run.log`.
- **A freeze while shaders compile is fixed.** On a first run (empty shader cache), the game could freeze for good: when building a shader hit a fault and recovered, the shader stayed marked as "being built" and every thread that needed it waited forever. Present since 0.3.6.9; seen in Uncharted 3. Now those marks are released when the build recovers.
- **Uncharted 3's aiming crosshair is round again at higher render resolutions.** With the render resolution above 1080p (for example native 1440p or ultrawide), the game scaled the crosshair by the render size: an oval about 1.8 times too wide and 1.3 times too tall. It now keeps its 1080p size and shape. EU and US.

## Known issues
- Uncharted 3: single-frame lighting flashes are rarer since 0.3.6.7 but may not be gone entirely.
- Uncharted 1 and 2 with Quality, Balanced or Performance, and Uncharted 2 at native resolution, work in the opening areas but haven't had a full playthrough (cutscene videos, HUD, menus).
- Ultrawide: short scripted scenes can still switch to 16:9 by mistake; **Always fill** avoids it.
- Rarely, the game freezes while exiting; if it happens, end `bb-probe.exe` in Task Manager.
- Fast mouse aiming covers the EU (CUSA02343) and US (CUSA02320) versions; other versions keep stick-style aiming.
- DLSS Frame Generation goes up to 4×.
