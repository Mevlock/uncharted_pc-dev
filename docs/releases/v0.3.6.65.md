**Installing:** the launcher of 0.3.6.30 or newer offers this update itself; or unpack into a new folder and start `Uncharted.exe`.

## New: optional frame pacing (off by default)
- **Frame pacing is back as a choice you make yourself.** It shows each frame at an even moment and moves the game's
  world by those same steps, for smoother motion at a capped frame rate. It is **off unless you turn it on**: nothing
  changes for you if you leave it alone.
- **Where:** in the launcher, on the **Display** page under **Frame rate limit**: **Frame pacing**.
  - **Off** (the default): each frame is shown as soon as it is ready, as in 0.3.6.64.
  - **Balanced**: smoother motion; the graphics card is handed each frame just before its moment, so it stays only a
    little busier. Best tried at a frame rate limit your PC holds comfortably.
  - **Smoothest (uses more GPU)**: the graphics card itself waits for each frame's moment, as in 0.3.6.59 and 0.3.6.60
    (with this build's fixes). The most even timing, but the card stays busier and can lose frames when near its limit.
- **If you turned pacing on with an Environment entry** for 0.3.6.60.1 (`BB_EVEN_PRESENT=1` on the **Advanced** page):
  that entry still wins over the setting; remove it and use the setting instead.
- **If something goes wrong with it on:** set it back to Off, and send `user/last_run.log` from that run.

## Launcher
- **Go back to an earlier version, and forward again:** **Advanced > Updates > Version** lists the releases from
  0.3.6.57 on (test builds with **Show test builds**). The version you leave is kept in a `versions` folder next to the
  launcher, so **Back to** returns to it at once, without a download (**Remove backups** frees that space); saves,
  settings and the shader cache are not touched. From a version older than this one, its **Update** button brings
  you back to the newest.
- **Open log folder** on the **Log** page, and beside the message when the game stops with an error: Explorer opens
  on the folder with `last_run.log`, the file selected, ready to attach to a report.

## Fixes
- **Checkpoints page in the in-game menu:** a double click on a checkpoint now also closes the menu once the jump
  starts, so the game is in view at once.
- **Button pictures** (keyboard, Xbox, Nintendo) are painted on their own thread, so prompts appearing no longer cause
  small hitches, and the HUD and Controls pictures no longer stay on the PlayStation ones when they first appear while a
  menu opens, closes or fades.
- **Data the game reads back from the graphics card** is handed over only once it is complete (rare one-frame
  glitches).
- **The pipeline cache save** no longer ends the game when memory is short; the save is made at the next chance.
- **Upscalers and frame generation** are given the game's own time between frames instead of the port's internal
  timing, which could vary.
