**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. This is SuperMedo's 0.3.6 plus this fork's changes; everything in 0.3.6.13 plus the list below.

**Installing:** unpack into a new folder and start `Uncharted.exe`. Your launcher settings carry over, but saves live in each install's own `user\savedata` folder: copy that folder over from your previous install, or set **Saves folder** in the launcher to it.

## New in 0.3.6.14
- **Native 4K, experimental**, in all three games: the launcher's **Render resolution** list has two new choices, **3840 × 2160 (4K, experimental)** and **3840 × 1600 (21:9 4K, experimental)**. They draw the picture at that size whatever the window (on a smaller screen the picture is scaled down, which sharpens it like supersampling). Until now the games' memory layout stopped the picture at about 3440 × 1440: the render targets didn't fit the 4 GiB the games keep for graphics. Above that size the largest render target heap now moves to the games' CPU memory, which has the room (the approach of [BilalReloaded's Uncharted port](https://github.com/bc160201983/Uncharted-The-Nathan-Drake-Collection-PC-port)); Uncharted 1, whose engine keeps pointers within a 2 GiB window of that memory, takes it from the far end so its levels stay inside. **Experimental:** only short tests so far, standing still in one area per game (no level loads, cutscenes or long sessions), and not on a 4K screen. Measured at 3840 × 2160 with DLSS: Uncharted 1's jungle about 88 FPS, Uncharted 2's museum about 78, Uncharted 3's Cartagena square about 72 (10-minute runs, no errors). **Native** and the Quality, Balanced and Performance modes stay as they were, so nothing changes unless you pick a 4K choice.
- **`last_run.log` now starts with the build:** its first line names the version, the commit, the install folder and the game started.

## Known issues
- Native 4K (the two experimental Render resolution choices) has had only short tests; if a game crashes or looks wrong with one, go back to Native.
- Uncharted 3: single-frame lighting flashes are rarer since 0.3.6.7 but may not be gone entirely.
- Uncharted 1 and 2 with Quality, Balanced or Performance, and Uncharted 2 at native resolution, work in the opening areas but haven't had a full playthrough (cutscene videos, HUD, menus).
- Ultrawide: short scripted scenes can still switch to 16:9 by mistake; **Always fill** avoids it.
- Rarely, the game freezes while exiting; if it happens, end `bb-probe.exe` in Task Manager.
- Fast mouse aiming covers the EU (CUSA02343), US (CUSA02320) and EU/Russian (CUSA02344) versions; other versions keep stick-style aiming.
- DLSS Frame Generation goes up to 4×.
