**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. Everything in 0.3.6.41 plus the changes below.

**Installing:** the launcher of 0.3.6.30 or newer offers this update itself; or unpack into a new folder and start `Uncharted.exe`.

**Your saves:** the first time you start a game with this version, before anything else touches your saves, the port copies every save of your copy of the collection (all three games, progress and profile) to `user\savedata\1\<title id>.backups\before-save-slots`. It does this once and never overwrites that copy.

## New
- **Checkpoints (all three games):** the in-game menu (Insert, or L3+R3 on a controller) has a Checkpoints page: pick a chapter and a checkpoint and the game goes there, using the game's own checkpoint jump (the one Naughty Dog's developer menu used). It works across levels and in every version the port supports (EU, US, EU/Russian and Spanish, 1.00 and 1.02).
  - **Practice mode:** after a jump, the game saves to a practice copy until you restart it, so jumping around never changes your own save. **Keep this progress** makes the practice save your save (the game restarts and Continue starts there), for example to get past a place that does not work for you.
- **Save slots (all three games):** a Save slots page in the same menu:
  - **Five slots per game:** save your current progress into a slot and load it later (the game restarts and Continue starts there). The save you had before a load is kept as "Before the last load".
  - **Story save:** a copy of your playthrough that follows you as you play on, and stays where it is when you go back or skip ahead with Chapter Select. If your save has moved away from it, the page says so and **Load story save** takes you back; **Make this my story save** keeps a skip on purpose.
  - **Where you are:** the page shows the checkpoint and chapter your save is at.

  Your treasures, unlocks and trophies (the profile save) are never changed by any of this.
- **Nintendo button pictures:** a Switch Pro Controller or Joy-Cons get Nintendo pictures in the games' prompts (B A Y X by position, L R ZL ZR, + and −). Launcher, Controls, "Show in the game" also offers them as a fixed choice.
- **Controller vibration settings:** on/off and a strength slider, plus Detect controller and Test vibration buttons (launcher, Controls; by poncho-ajmv).
- **Launcher language:** the launcher can be shown in English, Spanish, Portuguese, French, German, Italian or Japanese, or follow Windows (launcher, Advanced; by poncho-ajmv). Every launcher text is translated; the newer texts were translated for this release and have not been checked by native speakers yet.
- **Spanish release (CUSA02826):** its shader index now ships with the port, so it gets shader preparation by default like the other releases, without reading all the game files first.

## Changed
- **More shaders prepared ahead:** a few more pipelines and variants from recent play (Uncharted 1 +2, Uncharted 2 +2, Uncharted 3 +3).
- **The game version shown in the launcher** is now right for releases whose files call themselves 1.00 although they hold the 1.02 game (the Spanish 1.02 package, EU/Russian 1.02 copies).
