**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. Everything in 0.3.6.31 plus the changes below. It replaces 0.3.6.32, which was withdrawn the same day; if you already have 0.3.6.32 there is nothing to undo.

**Installing:** the launcher of 0.3.6.30 or newer offers this update itself; or unpack into a new folder and start `Uncharted.exe`.

## Fixed
- **The shader cache stays with each install.** If you had set a **Saves folder** in the launcher, every version you unpacked used the shader cache of the install that folder belonged to. Versions then kept rebuilding or pruning each other's caches, which meant long first starts and stutter in places that should have been smooth. Saves, trophies and settings still follow your Saves folder; the shader cache now always lives in the install's own `user\cache` folder.
- **No long first start when you use a Saves folder.** On its first start this version copies the shader cache you already have in your Saves folder into the install (the Saves folder keeps its copy for older versions). In 0.3.6.32 this copy was missing: those players started from an empty cache, prepared every shader again and could see a black window for several minutes on a hard drive while the game files were searched.
- **Uncharted 1 at high frame rates:** objects, debris and bodies come to rest after the same time at any frame rate. Above 60 FPS they settled too early (at 144 FPS in about 40% of the time), and the game's slow-down of moving objects was applied per frame instead of per second.
- **Fewer first-play hitches:** one more Uncharted 1 shader and two pipelines (near the start of chapter 4), and 28 Uncharted 3 shaders and 32 pipelines (chapter 1 pub fight, chapter 21 Ubar cistern) are prepared ahead.

## For bug reports
The first lines of `last_run.log` now also show where your saves and your shader cache are.
