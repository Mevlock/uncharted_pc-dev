**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. Everything in 0.3.6.48 plus the changes below.

**Installing:** the launcher of 0.3.6.30 or newer offers this update itself; or unpack into a new folder and start `Uncharted.exe`.

## New
- **Unlock all rewards** (by BilalReloaded): launcher **Game → Unlock all rewards**, under Unlock all chapters. Every reward in Bonuses (skins, weapons, render modes, art galleries, and gameplay tweaks such as Slow Motion and Mirror World) and every story cutscene, in all three games. Rewards that normally need the game finished first can be turned on right away. Nothing is written to your save: turn it off and the menus show your own progress again. Treasures, medals and trophies are not touched. Works on update 1.00 and 1.02, EU and US.
- **5.1 and 7.1 surround sound** (from drakolordx7's change in SuperMedo's port): the games now see your real speaker setup and offer their own 5.1 and 7.1 mixes in their Audio Output menu. Launcher **Display → Audio → Speakers**: Automatic (the Windows speaker setup), Stereo, 5.1 or 7.1. Stereo speakers and headphones keep the games' stereo mix.
- **Separate aiming and vertical mouse sensitivity:** launcher **Controls**, two new sliders under Mouse sensitivity. *Aiming sensitivity* multiplies the sensitivity while you aim (right mouse button or L2); *Vertical sensitivity* multiplies up and down movement. Both are 1.00 by default, the same as before. The in-game menu (Insert) has a new **Mouse** section with all three, which change at once while you play.
- **Walk key and valve keys** (by drakolordx7): hold **Left Ctrl** with the movement keys to walk instead of run (**Walk speed** slider on the Controls page, 65% by default). Hold **R** or **T** to turn the left stick in circles, counter-clockwise or clockwise, for valves, cranks and wheels. If you already use one of these keys, the new action is left unassigned and you can bind it on the Controls page.
- **Alt+Enter** switches between fullscreen and a window while you play. It switches when the window has the same shape as your screen (for example a 2580×1080 window on a 3440×1440 screen); the game's view and render size are set at start, so other sizes need a change in the launcher.
- **The controller can keep working in the background:** launcher **Controls → Keep the controller working in the background**, off by default. Handy with the game on a second screen. The keyboard and mouse still only work while the game window is in front.
- **Reset all settings:** launcher **Advanced → Reset**, with a confirmation. Every option goes back to its default; your game folders, saves folder, languages, player name and cover art are kept, and saves are never touched.
- **Launcher in Russian:** **Advanced → Interface language → Русский**, and picked automatically on a Russian Windows. Most of it is poncho-ajmv's translation from SuperMedo's port; the rest is new and hasn't been checked by native speakers yet. The in-game menu stays in English for Russian.
- **Checkpoints page** (in-game menu, Insert): the checkpoint you're at is always marked, and the page opens at its chapter. Double-click a checkpoint to go there. Naughty Dog's leftover test entries are no longer listed.

## Fixed
- **Video memory on 4–6 GB graphics cards:** on long sessions Uncharted 2 kept taking more video memory as you moved through new areas, until a smaller card ran out. The port now reuses memory it hasn't needed for a while instead of taking more, earlier on smaller cards and on any card once 80% of its memory is in use. In our test (30 minutes of Uncharted 2 across chapters, on a 16 GB card set up to act like a 6 GB one) memory use levelled off at about 3.8 GB instead of climbing past 4.5 GB. Set up to act like a 4 GB card, it stayed within the card's memory for the whole half hour. These were simulated small cards, not real ones.
- **Saves repair themselves after a crash or power cut:** each save is backed up when the game finishes writing it. If a save file is later found empty or zeroed (the game was cut off while writing), it is put back from that backup. A save the game cleared on purpose is left alone, and a good save is never overwritten.
- **Several controllers connected:** the game now follows the controller you're actually using, not only the first one Windows lists (from spacepepperoni's Linux port). A virtual copy of your controller (Steam Input, DS4Windows) no longer makes the port switch back and forth, which cut out rumble and moved the light bar.
- **Games on update 1.00 stopping when a job ran before it was ready** (all three games): the guard added for 1.02 in 0.3.6.48 now covers 1.00 too.
- **Uncharted 3 stopping with an error in some lit scenes** (from BilalReloaded's port): a light whose shadow camera came out invalid is now skipped for that frame.
- **Fewer first-time stutters:** more of the games' shaders are prepared before you play (Uncharted 1 +36 variants, Uncharted 2 +24, Uncharted 3 +10, plus pipeline and compute keys), collected from play and test sessions on EU, US, EU-Russian and Spanish releases.
