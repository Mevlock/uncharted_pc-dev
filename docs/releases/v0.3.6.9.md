**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. This is SuperMedo's 0.3.6 plus this fork's changes; everything in 0.3.6.8 plus the list below.

**Installing:** unpack into a new folder and start `Uncharted.exe`. Your launcher settings carry over, but saves live in each install's own `user\savedata` folder: copy that folder over from your previous install, or set **Saves folder** in the launcher to it.

## New in 0.3.6.9
- **Uncharted 3's flashlight no longer drops out, and the lighting glitches in Uncharted 2 are gone.** While the camera turned, the flashlight's light could vanish for a frame and come back as blocky dark squares. The shadow maps of all the lights live in one stack of layers that changes size as you turn; the port rebuilt that stack one layer at a time and lost the layers already drawn. It now keeps every layer. The same happened in Uncharted 2. No FPS cost in any of the three games (measured with the fix on and off).
- **Much less stutter the first time you see something new** (from [drakolordx7's fork](https://github.com/drakolordx7/uncharted_pc), PRs #389/#416): stored shaders load on background threads at start, and new shaders and pipelines compile off the GPU thread. Shaders compile again once on the first start.
- Crash fixes from SuperMedo's open pull requests:
  - Uncharted 2: the "iSubMesh < m_numSubMeshInstances" assertion, mostly just after a checkpoint save (#397).
  - "EOP tick check not found" in some Uncharted 1 builds (#405).
  - Launches that stopped with "reserving the PS4 address range ... failed" (error 487) now start again by themselves (#406).
  - A rare stop with exit code 23 while preparing draws (#409).

## Known issues
- Uncharted 3: single-frame lighting flashes are rarer since 0.3.6.7 but may not be gone entirely.
- Uncharted 1 and 2 with Quality, Balanced or Performance, and Uncharted 2 at native resolution, work in the opening areas but haven't had a full playthrough (cutscene videos, HUD, menus).
- Ultrawide: short scripted scenes can still switch to 16:9 by mistake; **Always fill** avoids it.
- Rarely, the game freezes while exiting; if it happens, end `bb-probe.exe` in Task Manager.
- Raw aim covers the EU version (CUSA02343) and has untested locations for CUSA02344; the US version (CUSA02320) keeps the old stick-style aiming.
- DLSS Frame Generation goes up to 4×.
