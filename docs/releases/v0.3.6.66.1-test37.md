**Test build for [issue #37](https://github.com/Mevlock/uncharted_pc-dev/issues/37)** (Uncharted 2 and 3 sitting on a black screen for several minutes at start-up). It is 0.3.6.66 plus a new shader cache. It is a test build and not for general use; the normal release stays [the latest one](https://github.com/Mevlock/uncharted_pc-dev/releases/latest). Unofficial fork build; the official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc).

**Installing:** unpack into a new folder and start `Uncharted.exe` (or over a copy of your install; your saves and settings in `user` are kept).

> **A big thank you to [antikmewzik](https://github.com/antikmewzik)** for his keyboard, mouse and controller work
> ([uncharted_pc_controls_qol](https://github.com/antikmewzik/uncharted_pc_controls_qol)): the button prompts, the mouse in
> the menus, the Keyboard / Mouse menu row and the menu cursor of all three games are built on his code and research.

## What changes
- **The shader cache is now one file** instead of thousands of small ones. The long black screen on later starts came from reading all those files; reading one file should remove it.
- **The first start prepares the shaders once more**, because the cache has a new format. Later starts should go straight into the game.

## What to do
1. In the launcher, use **Clear shader cache**.
2. Start the game and let the preparation finish (it shows a preparation screen).
3. Close the game and start it again.
4. Attach the `user\last_run.log` of that **second** start to issue #37.
