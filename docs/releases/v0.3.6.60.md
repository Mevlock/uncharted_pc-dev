**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. Everything in 0.3.6.59 plus the changes below.

**Installing:** the launcher of 0.3.6.30 or newer offers this update itself; or unpack into a new folder and start `Uncharted.exe`.

## Faster on most CPUs
- **Reserved CPU cores for rendering (on by default).** The two threads that prepare each frame for the graphics card
  now each get a CPU core of their own, so the game's other threads no longer keep interrupting them. On a CPU with
  enough cores to spare, the core of the busier of the two is kept for it alone; on smaller CPUs the other threads can
  still use it, so the game itself never runs short.
  - Measured at the U3 market (EU 1.02, render size Performance, uncapped): a 4-core / 8-thread CPU at 60% clock
    **+7 to +12%** (horse ride +10%), Ryzen 7 9800X3D **+7%**, Ryzen 7 5800X **+4%** with the lowest frame rates
    **+8%**. Worst frame times unchanged, picture unchanged.
  - **Uncharted 2, chapter 13 (the train), RTX 5080 + 9800X3D:** the heavy views where the frame rate used to drop to
    about 103 FPS now stay above 110 (most of the time above 120).
  - The gain is largest where the CPU is the limit (busy scenes, slower CPUs, lower render sizes); a game that is
    limited by the graphics card changes little. CPUs with fewer than 4 cores, or without two threads per core, are
    unchanged.
  - **Launcher:** Settings, Performance, "Reserve CPU cores for rendering" (on by default). Turn it off only if another
    program needs those cores.
