**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. Everything in 0.3.6.54 plus the changes below.

**Installing:** the launcher of 0.3.6.30 or newer offers this update itself; or unpack into a new folder and start `Uncharted.exe`.

> **A big thank you to [antikmewzik](https://github.com/antikmewzik)** for his keyboard, mouse and controller work
> ([uncharted_pc_controls_qol](https://github.com/antikmewzik/uncharted_pc_controls_qol)): the button prompts, the mouse in
> the menus, the Keyboard / Mouse menu row and the menu cursor of all three games are built on his code and research.

## Keyboard and mouse
- **Key bindings in the game.** The in-game menu (Insert) has a new **Controls** tab with the same settings as the
  launcher's Controls page: mouse look, the sensitivity sliders, invert, and two keys or mouse buttons for every action.
  Click a box and press the new key; changes work at once and are saved for the launcher too.
- **Options > Controls > Keyboard / Mouse** in all three games opens that tab (from antikmewzik's port).
- **Enter and Backspace work in the games' menus** (select and back), next to your own keys.
- **New menu cursor:** a golden arrow in the games' menus, which changes over buttons and when clicked
  (antikmewzik's). The in-game menu (Insert) shows a single cursor, also in exclusive fullscreen.

## Fixes
- **Photo mode Brightness no longer gives "deep-fried" colours.** Above about 90 the dark parts of the picture turned
  blotchy purple and green in all three games. The picture is now simply brighter, and normal play is unchanged.
- **Photo mode can be switched on again:** *Options > Game > Photo Mode Enable* is back in all three games. Once it's on,
  d-pad down opens photo mode in play, as on PS4. With keyboard and mouse, d-pad down is the Down arrow and the mouse wheel.
- **Switching games from the collection menu could stop the game** when it was started without a console window (for
  example from Steam). Reported upstream as #830.
