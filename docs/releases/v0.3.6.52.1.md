## Fix
- **Chapter Select and New Game no longer show a "Save game" list.** In 0.3.6.52 the new save list also appeared when
  a game asked where to save, and choosing *New save* there started a second campaign save next to your first one: the
  game went on in the new one, while the save slots, the story save and *Current save* kept using the first. The games
  now save to your one campaign save again, as before 0.3.6.52. The list stays for **Load game**.
- If you already made a second save that way, it is kept: it shows in the game's own lists, and nothing was deleted.
