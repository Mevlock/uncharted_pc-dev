**Installing:** the launcher of 0.3.6.30 or newer offers this update itself; or unpack into a new folder and start `Uncharted.exe`.

## Fixes
- **Uncharted 3, chapters 13 and 14: no more red flashes on the ship.** The deck trim, the pool rim and the window
  strips of the cruise ship could flash flat red for a frame, most often at the big wave. The ship's position for a
  frame could be read while the game was still updating it, so one pass drew the ship a frame behind the others.
- **Uncharted 3: no crash when you start a new save while practising.** Chapter Select or New Game onto *New save* in
  practice mode could stop the game; the new save is now found right after it is made.
- **Load Game could hang** (seen in Uncharted 3): a timer the game waits on could be missed. Fix from iannitram's
  Uncharted Universal.
- **Uncharted 1, One-Hit Kills:** Elena's shots from the jet ski now kill at once too.
- **Uncharted 3, the cruise ship's container yard:** the fix that stops Drake falling through the ship after a restart
  (0.3.6.47) now only acts on the impossible jump it was made for. In busy moving-platform scenes it also caught ordinary
  steps between moving platforms, which could make Drake or an enemy hop.
- **Checkpoints (Insert menu): picking the checkpoint you are at no longer empties the scene** in Uncharted 1 and 2 (no
  Drake, no enemies, no HUD). *Go there* is off for the current checkpoint. Fix from El Dorado (michelle).
- **Depth and stencil:** a depth buffer's stencil is no longer linked to an unrelated picture the game keeps at the
  same place in memory. Fix from iannitram (after Pepin208's port of two shadPS4 fixes).
