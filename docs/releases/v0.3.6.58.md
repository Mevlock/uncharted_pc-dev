**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. Everything in 0.3.6.57 plus the changes below.

**Installing:** the launcher of 0.3.6.30 or newer offers this update itself; or unpack into a new folder and start `Uncharted.exe`.

## Uncharted 2
- **Chapter 22 (The Monastery): the "invisible sniper" on the walkway to the tower is fixed.** This is a bug in the
  original game too. The bridge's last wave of soldiers spawns inside the tunnel behind the far gate and has to walk
  out, but the gate closed 4 seconds after they spawned while they needed about 10 seconds to get through. Whoever was
  still inside was shut in: unseen, but still counted as alive, so the game killed Drake on the walkway to the tower
  (even with infinite health), with a shot from the gate. The gate now stays open until everyone is out, then closes as
  before. A sniper that spawns behind the gate after it has closed now comes out on the bridge side. Both versions of
  the game (1.00 and 1.02). `BB_U2_MONASTERY_SNIPER=0` turns the fix off.

## Launcher
- **Clear shader cache no longer freezes the launcher.** The cache was deleted while the window waited, which took
  minutes with a large cache and looked like a hang. The cache folder is now set aside at once (the next start finds an
  empty cache) and deleted in the background; anything a closed launcher left behind is removed at its next start.
