**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. Everything in 0.3.6.44 plus the changes below.

**Installing:** the launcher of 0.3.6.30 or newer offers this update itself; or unpack into a new folder and start `Uncharted.exe`.

## Fixed
- **Save slots can no longer stop the game at start:** a file problem in the save slot code (for example an unusual saves folder) could end the game without an error message while it started. Now the problem is written to the log ("Save slots: … failed") and the game goes on; your saves are left as they were.

## Changed
- **Nintendo button pictures are switched off for now:** a Nintendo-style controller shows the Xbox pictures, and the launcher's "Nintendo buttons" choice is gone until they are tested further. If you had it selected, the launcher is back on Automatic.
