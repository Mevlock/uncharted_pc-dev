**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. This release is **0.3.6.58** again, with a new version number.

**Installing:** the launcher of 0.3.6.30 or newer offers this update itself; or unpack into a new folder and start `Uncharted.exe`.

> **A big thank you to [antikmewzik](https://github.com/antikmewzik)** for his keyboard, mouse and controller work
> ([uncharted_pc_controls_qol](https://github.com/antikmewzik/uncharted_pc_controls_qol)): the button prompts, the mouse in
> the menus, the Keyboard / Mouse menu row and the menu cursor of all three games are built on his code and research.

## Back to the 0.3.6.58 base
- The frame pacing added in 0.3.6.59 caused problems on many PCs (lower FPS, high GPU usage, uneven frames). This
  release goes back to 0.3.6.58's code, so frames are timed exactly as in 0.3.6.58, while the pacing is reworked.
- The other changes of 0.3.6.59 and 0.3.6.60 are not in this release either; they come back in a later release once
  they are ready together with the new pacing.
- If you added `BB_EVEN_PRESENT=0` or other switches from 0.3.6.59 / 0.3.6.60 to the launcher's Environment field,
  you can remove them; they do nothing here.
