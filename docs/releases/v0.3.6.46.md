**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. Everything in 0.3.6.45 plus the changes below.

**Installing:** the launcher of 0.3.6.30 or newer offers this update itself; or unpack into a new folder and start `Uncharted.exe`.

## Fixed
- **Uncharted 2: invisible, silent gun after Chapter Select:** starting some chapters from the game's Chapter Select (for example chapter 8, *The City's Secret*, or chapter 13, *Locomotion*) left Nate with a pistol that was invisible and made no sound, and no rifle. This comes from the original game: Chapter Select resets Nate to a default pistol, and in 11 chapters the first checkpoint doesn't give back that chapter's own weapons, while the level never loads the default pistol's model. Nate now starts those chapters with the checkpoint's own weapons (mostly a Beretta, a rifle and a grenade), as if you had played into it. Chapters 6–10, 13, 14, 18, 20, 23, 24 and 26; Continue, restarts and the other chapters are unchanged.
- **DLSS: vertical stripes after loading:** with DLSS (most visible with the newer models at 4K), fine vertical stripes could appear for 3–4 seconds while the picture faded in after loading or restarting a checkpoint, for example in the Uncharted 2 ice cave. DLSS now starts its picture history afresh while the scene fades in.
- **Controller hitch:** reading the controller no longer holds up the game, so connecting, disconnecting or switching controllers no longer causes a short freeze.
- **Uncharted 2: a crash after jumping to a checkpoint:** a texture setting the game was rewriting at that moment could end the game with an error; it now takes a usable value instead.
- **Frame generation flickering on and off:** near 165 FPS, frame generation could switch on and off repeatedly, which felt like stutter. It now pauses above about 175 FPS and comes back below about 158.
- **Fewer shader compiles while playing:** damaged entries in the shipped shader lists were repaired and outdated entries in the shader cache are removed, so more shaders are ready before play starts. The FPS counter now also shows how many shaders were compiled during play.
- **Overlay Checkpoints page:** Uncharted 3's chapter list no longer shows chapter 12 twice.
- Rendering fixes from a code review of the renderer, and a rare problem with depth textures that are read while they are being drawn to.

## Added
- **Sharper DLSS/FSR option:** Anti-aliasing sharpness has two new steps above High: Very high and Maximum.
- **Cheats:** No Reload (Uncharted 2 and 3) and One-Hit Kills (Uncharted 3).
- **Intel Arc:** shaders use dynamic vertex input on Arc cards.
