**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. Everything in 0.3.6.37 plus the changes below.

**Installing:** the launcher of 0.3.6.30 or newer offers this update itself; or unpack into a new folder and start `Uncharted.exe`.

## Fixed
- **GeForce GTX 10-series cards: crash at start.** An optional driver feature the port uses for crash reports is now off on NVIDIA cards older than the RTX 20-series. If your GTX 10-series card did not start the games before, please tell us if it does now.
- **Intel graphics:** compute shaders now always run with the lane width they were built for, where the driver could otherwise pick another one per shader (wrong results in some effects).

## Changed
- **Depth of field** (launcher, Display page): the choices now say what they do: **Off only while aiming** and **Off everywhere** (also cutscenes and takedowns). Your choice is kept.

## Faster
- **Fewer shader compiles while playing Uncharted 1:** more shader variants and pipelines in its list, prepared at start.
