**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. Everything in 0.3.6.52.1 plus the fixes below.

**Installing:** the launcher of 0.3.6.30 or newer offers this update itself; or unpack into a new folder and start `Uncharted.exe`.

## Fixes
- **Checkpoint jumps no longer change your second campaign save.** Jumping to a checkpoint from the overlay puts the
  game in practice mode, so your own save is not touched. Until now that only covered a game's first campaign save. If
  you had a second one (0.3.6.52's Chapter Select made one, and *Continue* picks the newest), the jumps were saved into
  it. Practice mode now covers all of a game's campaign saves.
- **The launcher shows the shaders as prepared on AMD and Intel graphics.** After *Prepare shaders* it kept saying
  "not prepared yet" on those cards, although the preparation had worked (the game itself started without preparing
  again).
- **A crash at some loads is caught:** textures with a layout the GPU does not have (read from game data before the game
  filled it in) are now skipped instead of stopping the game.

## Faster
- **Busy scenes wait less for the GPU.** In scenes with many animated characters the game keeps rewriting memory the GPU
  used a few frames before, and each time the game thread waited for that data. The port now copies it back ahead of time.
  Measured in Uncharted 3's Caravan horse chase (3440x1440, RTX 5080, four runs each): about **+4%** average on a fast
  CPU, and with the same PC limited to 8 threads at 60% speed (a stand-in for a slower CPU) about **+20%** average and
  **+14%** in the worst 20 seconds. Other places hardly change (Uncharted 3's market, Uncharted 2's convoy and Uncharted 1's
  first fight: between -1% and +2%). Your numbers will differ with your CPU, GPU and settings.
  `BB_PREFETCH_READBACK=0` (launcher, Advanced > Environment) turns it off.
