**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. Everything in 0.3.6.35 plus the changes below.

**Installing:** the launcher of 0.3.6.30 or newer offers this update itself; or unpack into a new folder and start `Uncharted.exe`.

## New
- **Developer mode** (launcher, Cheats page, for each game): Naughty Dog's own developer features, left in the games but switched off. The game files are not changed.
  - The developer text on screen (frame rate and timings).
  - **F11** opens the Dev Menu, **F8** the Quick Menu (Uncharted 2 and 3; Uncharted 1 has the Dev Menu only). Use the controller in the menus.
  - Dev Menu → **Tasks** lists every checkpoint of the current level and the others: pick one to go there.
  - Quick Menu: Invincible Player, Infinite Ammo and Grenades, One Hit Kills, Super Pause, Bonuses and more. Uncharted 3 also has a Camera menu under Player Menu.
  - Works on game versions 1.00 and 1.02. Developer tools can change your save (Bonuses, treasures and medals) and some may not work outside the developers' own consoles.

## Fixed
- **Uncharted 3 bloom:** the bloom pass can no longer darken the picture (its negative values are clamped to zero).
- **Black patches with modified game files:** game files patched to switch on developer mode (outside the port) can show dark patches and keep the port from recognising the game. Use your original files and the new Developer mode option instead.
