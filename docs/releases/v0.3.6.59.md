**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. Everything in 0.3.6.58 plus the changes below.

**Installing:** the launcher of 0.3.6.30 or newer offers this update itself; or unpack into a new folder and start `Uncharted.exe`.

> **A big thank you to [antikmewzik](https://github.com/antikmewzik)** for his keyboard, mouse and controller work
> ([uncharted_pc_controls_qol](https://github.com/antikmewzik/uncharted_pc_controls_qol)): the button prompts, the mouse in

Shaders prepared with 0.3.6.58 stay valid: no new preparation after this update (the first start adds a few dozen new
shaders in about a second).

## Smoother frames
- **Even frame pacing with a frame rate cap.** With the launcher's frame rate cap, each frame is now held on the GPU until
  its time slot, so frames reach the screen at an even spacing instead of in small bursts, and the game's world moves by
  exactly that spacing. On the developer's PC (RTX 5080, U3 desert horse ride) the spread of the time between frames on
  screen fell from about 1 ms to 0.26-0.45 ms at 60, 120 and 144 FPS, and frames more than 2 ms off their slot from 4-6 %
  to under 1 %. Frames that are already late are not held, and when the graphics card cannot keep up with the cap the hold
  steps aside, so a cap set too high is no worse than before. Same on NVIDIA, AMD and Intel.
  - **For the smoothest result, pick a cap your PC holds steadily** (for example 60 on a modest PC) and use only the
    launcher's cap: an external limiter at the same time (RivaTuner, the driver's frame limit) can fight with it.
- **The cap now waits at the start of the game's frame** instead of just before the frame is shown, so the frame you see
  was started from newer input.
- **No late frame every few seconds.** The port's own log output could make the render thread wait for the launcher; it
  now goes through its own thread.
- **No hitch when button pictures appear.** The controller and keyboard button pictures are drawn on their own thread.

## Uncharted 3
- **Desert horse ride (chapter 18): the hitches in the canyon are fixed.** Scenery streamed in during the ride is sent to
  graphics memory ahead of time, and both screen-size versions of the frames are kept, so neither stalls a frame.
  Streaming ahead is only used on cards with 5 GB of video memory or more.
- **One-frame camera snaps are fixed.** Animated camera shakes (for example while riding) ended at full strength in a
  single frame. This is a bug in the original game too (also on PS4); they now fade out.
- **The flicker around Nate at a 60 FPS cap is fixed.** Some data the game reads back from the GPU was occasionally used
  before the GPU had finished writing it, which made Nate's motion blur flicker, mostly on the horse.
- **One-Hit Kills now kill armoured enemies.**

## Uncharted 2
- **One-Hit Kills now kill armoured enemies**, both versions of the game (1.00 and 1.02).

## DLSS, FSR and frame generation
- **Riders and vehicles: less smearing.** Nate on the horse, and characters on vehicles and moving platforms, get their
  own motion, so the upscaler no longer treats them as part of the background.
- **Steadier image with a cap:** the upscaler and frame generation are told the world's real time step per frame.

## FPS counter
- **G-SYNC / FreeSync indicator (optional, off by default).** In the in-game menu (Insert), Settings, Other:
  "G-SYNC / FreeSync indicator". The FPS counter then shows a green **G-SYNC** on NVIDIA or a red **FreeSync** on AMD while
  the display refreshes with the game's frames, and a grey "... off" when it does not (for example in a window or outside
  the display's range). On AMD this needs the Adrenalin software. When it is off, nothing is checked at all.
  - This is mostly included for testing purposes: it helps check that variable refresh is really active while the game
    runs. It is a quick visual check, not a replacement for the display's or the driver's own indicator.

## Launcher
- **Collection menu** button on the Play page: starts the collection's own menu, where any of the three games can be
  picked, as on the PS4. In that menu the mouse now works on the game carousel: click its left or right arrow, or use the
  wheel.
- **Portable** option on the Game page: keeps the launcher settings in the game folder instead of your user folder
  (handy for a USB drive or a second copy); turning it off moves them back.
- The low latency option now names NVIDIA Reflex / AMD Anti-Lag 2 and NVIDIA Reflex Boost.

## Fixes
- **A crash with very little free memory at the first DLSS frame is fixed:** saving the driver's shader cache could end
  the game; the save now waits until there is room.
- **Some AMD start-up failures are fixed:** the memory the port's hooks need next to the game is now reserved before the
  graphics driver starts, so it can no longer be taken first.
- AMD: object motion no longer loses device (from BilalReloaded's port); FSR on some AMD APUs (Steam Deck class, Z1
  Extreme) no longer asks for protected memory (patch from iannitram's Uncharted-Universal); float atomic min/max on cards
  without the float atomics extension run one atomic instead of two (shadPS4 #5714).
