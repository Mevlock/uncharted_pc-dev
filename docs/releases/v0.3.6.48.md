**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. Everything in 0.3.6.47 plus the changes below.

**Installing:** the launcher of 0.3.6.30 or newer offers this update itself; or unpack into a new folder and start `Uncharted.exe`.

## New
- **Low latency mode: NVIDIA Reflex and AMD Anti-Lag 2** (by SuperMedo): launcher **Display → Low latency** (Off, On, On + Boost). It lets the game start each frame as late as possible, so your input reaches the screen sooner. Off by default. On our test PC (NVIDIA, Uncharted 3, 3440×1440) input reached the screen in about 11 ms with it on, and the frame rate did not drop. Anti-Lag 2 has not been tried on a Radeon card yet.

## Fixed
- **Uncharted 3: short freezes when a level loads or a cutscene starts** (from a fix by Alex): at these moments the game gives back video memory in many small pieces, and each piece made the port rebuild a much larger block of memory (5–33 ms each; at least 0.3 s in all on a fast PC, seconds on slower ones). The memory is now kept in smaller blocks, so these freezes are gone.
- **No sound on some PCs** (by drakolordx7): if the sound device refuses the game's audio format, the port now tries plain stereo, then Windows' DirectSound driver, before going silent.
- **Graphics fixes from shadPS4:** a texture that was reused although it lacked some of its layers is now recreated, a fast clear no longer gets the wrong colour when the game clears with a single value, and the GPU command reader no longer reads a command's size again after the game may have reused that memory.
