**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. Everything in 0.3.6.67 plus the changes below.

**Installing:** the launcher of 0.3.6.30 or newer offers this update itself; or unpack into a new folder and start `Uncharted.exe`.

> ([uncharted_pc_controls_qol](https://github.com/antikmewzik/uncharted_pc_controls_qol)): the button prompts, the mouse in

**The first start after the update prepares the shaders once more** (the shader cache has a new format and now also
holds the shaders for character motion vectors). It is a one-time wait with the preparation screen; later starts go
straight into the game.

## Changes
- **FSR 3.1 and FSR 4 at Quality, Balanced and Performance now render the game's scene at the render size.** Before,
  the game drew its scene at the full output size and FSR only scaled the result, so the scaled modes saved little on
  the graphics card. The scene is now really smaller, in all three games. On an RX 7800 XT the GPU busy time per frame
  was 10.8% lower at Quality and 16.1% lower at Performance than at native, at 2560x1440 (one PC, one test spot; the
  gain depends on how GPU-bound you are). FSR's
  extra texture sharpening (mip bias) is off by default now: it made fine patterns shimmer on sand.
- **Character motion vectors, as an option (off by default).** The launcher's *Character motion vectors* checkbox (also
  in the in-game graphics menu, or `character_motion` in `bbport.ini`) gives the upscalers and frame generation motion
  vectors for characters and other moving objects. Their shaders are prepared with everything else, only for the draws
  that need them, so turning the option on later needs no new preparation and no compiling while you play.
- **The shader cache is now one file** (`shaders.pack`) instead of about 30,000 small ones. Reading thousands of files
  was what made later starts slow, worst on portable or slow drives and with an antivirus scanning each file
  ([#37](https://github.com/Mevlock/uncharted_pc-dev/issues/37)). On our test PCs the whole cache now loads in about
  0.1 s.
  - An older cache of this port in the same folder is taken over or removed by itself. Shader caches of other builds
    or forks in the folder are left as they are.
  - The launcher's **Clear shader cache** still removes everything in the cache folder.
- **AMD graphics cards: later starts no longer rebuild every shader.** AMD's driver did not keep its compiled shaders
  between starts, so every start after the first rebuilt all of them. The port now keeps the driver's compiled shaders
  in `shaders.pack` itself. On an RX 7800 XT: Uncharted 3 about 12 s to 0.9 s, Uncharted 2 4.7 s to 0.4 s, Uncharted 1
  about 2 s to 0.2 s (one PC; times depend on the CPU and drive). Other cards whose driver offers this are covered
  too; NVIDIA keeps its own cache, which already worked.
- **The preparation screen shows whenever the game has to wait for shaders.** Before, Uncharted 3 on AMD could sit on
  a still screen for about 12 s without it. While the game waits, the preparation now uses all CPU threads (Uncharted
  3's first start on AMD: 41 s to 32 s).
- **Fewer shader combinations to prepare:** combinations that build the same shader are now one (Uncharted 1 2,223 to
  2,033, Uncharted 2 4,007 to 3,831, Uncharted 3 12,971 to 10,955, which also drops 1,847 Uncharted 1 and 2 combinations that had slipped into its list; Uncharted 3 never used them).

## Fixes
- **A crash when switching from DLSS to TAA** at an upscaled render size is fixed (the change is now taken over
  between frames).
- **The shader cache no longer freezes the game after the preparation screen.** On slow drives, the last flush of the
  cache to the disk could stall the game for several seconds right after the preparation. It is now flushed in steps
  while it is written.
- **Character motion vectors (option): identical characters** standing next to each other, and objects that stay in
  place, get their own correct vectors instead of swapping them; drawing them costs less.
- **Uncharted 2 and 3: one shader combination could not be prepared** because two different shaders shared the same id;
  the game built it while playing. It is now prepared.
- **Five shader translation fixes** for rarely used instructions (texture sampling with given slopes, half-float
  packing limits, the sign of an infinite reciprocal, wide-wave votes on graphics cards that run 32 lanes, and the
  object-motion data). They could give slightly wrong values in a few effects; nothing was seen on screen in tests.
