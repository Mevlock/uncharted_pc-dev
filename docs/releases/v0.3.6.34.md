**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. Everything in 0.3.6.33 plus the change below.

**Installing:** the launcher of 0.3.6.30 or newer offers this update itself; or unpack into a new folder and start `Uncharted.exe`.

## Fixed
- **Game version 1.00: no more long first start.** The port is made for version **1.02** of the collection. On 1.00 the shader preparation could not find the shaders where it expected them and searched through all the game files first, which takes many minutes on a hard drive and looks like a frozen black window. On a version other than 1.02 the launcher now skips the shader preparation (shaders are then built while you play) and says so on the Game page. Please update your dump to 1.02: parts of the port's fixes are made for its code and may not apply on 1.00.
- Dumps whose game information says 1.00 but which contain the 1.02 game (some EU/Russian CUSA02344 dumps) are recognised and keep the shader preparation.

## For bug reports
The first lines of `last_run.log` now also name the game and its version.
