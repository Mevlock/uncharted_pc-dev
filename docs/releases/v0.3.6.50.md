**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. Everything in 0.3.6.49 plus the changes below.

**Installing:** the launcher of 0.3.6.30 or newer offers this update itself; or unpack into a new folder and start `Uncharted.exe`.

## Faster
- **Higher frame rates where the CPU is the limit, especially in crowded scenes.** The renderer used to allocate and then free a small block of memory for every batch of draws (Uncharted 3's crowded market makes about 30,000 of these a second), which took up to a sixth of one of the renderer's threads. It now reuses those blocks.

  Measured in Uncharted 3's crowded market, 4 runs each, against 0.3.6.49, on one PC (RTX 4090, 3440×1440):

  | Setup | 0.3.6.49 | 0.3.6.50 | Average | Lowest moments |
  |---|---|---|---|---|
  | Native resolution, DLSS, no frame generation | 136.6 fps | 140.7 fps | +3% | +9% |
  | DLSS Performance, uncapped (CPU-limited) | 176.0 fps | 190.4 fps | +8% | +9% |
  | Same, with the CPU slowed down (8 threads at 60% speed) | 102.4 fps | 109.7 fps | +7% | +11% |

  The gain depends on your PC: it's largest when the CPU, not the graphics card, sets your frame rate (slower CPUs, lower resolutions, upscaling). If your graphics card is the limit, expect little change. The slowed-down CPU only stands in for a weaker processor; a real one may differ. Uncharted 1 and 2 build far fewer of these batches, so they gain less.

## New
- **The Menu key can be bound** on the Controls page (from poncho-ajmv's change in SuperMedo's port); the `[` and `]` keys are now always picked up too.

## Fixed
- **FIFO Relaxed** (launcher **Display → Presentation**) is now used when picked. Before, the game didn't recognise it and quietly used Mailbox instead (from spacepepperoni's Linux port).
- **Settings can't be lost to a crash or power cut while saving:** the launcher's settings, controls and in-game options are written to a temporary file first and swapped in only when complete, so the old settings stay intact if something goes wrong mid-save (from poncho-ajmv's change in SuperMedo's port).
- **Uncharted 3, update 1.00: the title music no longer plays on into the London Underground** after Continue at that chapter's checkpoint; the level's own music takes over as it should (from spacepepperoni's Linux port). Update 1.02 has different code here.
