**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. Everything in 0.3.6.42 plus the changes below.

**Installing:** the launcher of 0.3.6.30 or newer offers this update itself; or unpack into a new folder and start `Uncharted.exe`.

## New
- **Quit on the main menu (all three games):** the main menu has a Quit item at the bottom that closes the game, like any PC game. It uses the game's own "Quit" text, so it is in the game's language. If a save is being written, the game waits for it to finish first.
- **Quit on the pause menu (all three games):** the pause menu has a Quit item under Quit to Main Menu. It asks first with the game's own Yes/No (No is selected), because progress since the last checkpoint is lost, the same as with Quit to Main Menu.
- **What's new window:** after an update, the launcher shows that version's release notes once. Open them again from the version line under the logo, or from Advanced > Updates, which lists the five newest versions. The update offer also shows the new version's notes. Tick **Don't show this after updates** to turn the window off.

## Changed
- **The in-game menu follows the launcher's language** (Spanish, Portuguese, French, German, Italian, Japanese).
- **More of the launcher is translated:** drop-down choices, the Controls page actions and the trophy texts. The newer texts have not been checked by native speakers yet.
- **Bigger in-game menu:** the menu window grows with your screen resolution, and long grey notes wrap instead of being cut off.
