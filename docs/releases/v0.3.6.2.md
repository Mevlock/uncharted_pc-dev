**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. This is SuperMedo's 0.3.6 plus the changes below.

**Installing:** unpack into a new folder and start `Uncharted.exe`. Your launcher settings (game folder etc.) carry over, but saves live in each install's own `user\savedata` folder: copy that folder over from your previous install, or set **Saves folder** in the launcher to it.

## Performance
- **About twice the frame rate in busy scenes**, frame generation off, native 3440×1440: Uncharted 1 ~112 → ~151 FPS, Uncharted 2 ~44 → ~96, Uncharted 3 ~43 → ~97. The biggest fix: character skinning made the GPU stop and wait before almost every one of its ~100,000 jobs a second over a bookkeeping mistake. Details in `docs/PERFORMANCE_2026-10-18.md`.
- **Idle game threads sleep** instead of spinning on a core (from BilalReloaded's Uncharted port): about 7% more in Uncharted 3.

## Picture
- **Render resolution** (Display page): the games can render at your screen's resolution instead of enlarging 1920×1080, up to about 3440×1440. Uncharted 3 can also render smaller and let DLSS or FSR rebuild the full size (Quality, Balanced, Performance).
- **DLSS and FSR fixed in Uncharted 3:** the upscaler threw away its history every frame, so the picture never built up detail and the sub-pixel jitter showed as a constant shake (the title screen's rifle and dunes). Shimmering is basically gone. Textures keep their detail at reduced render sizes, and **Anti-aliasing sharpness** now works with DLSS.
- **Ultrawide** (21:9, 32:9) with a **Field of view** setting; menus and videos stay 16:9. New **Always fill** option never switches to 16:9 (menus stretched instead).
- **Bloom** on/off (Uncharted 3) and **texture filtering** (anisotropic).
- **Frame rate limit** that counts generated frames (e.g. 120 with frame generation).

## Fixes
- **Uncharted 3: Sully's shirt flashing** huge triangles in Cartagena above 30 FPS (the cloth shader read past its shared memory, which the PS4 answers with zeros). See the README for the full story.
- Uncharted 3: missing tutorial button text, treasure glints turning into white shapes at reduced render sizes, a frame-generation crash between menu and gameplay.

## Convenience
- **Skip intro logos** (and their music) in all three games.
- **Crash-safe saves:** a save is written to a temporary file and swapped in, so a crash while saving can't corrupt it.
- New in-game menu (Insert / L3+R3) and a compact FPS counter with 1% lows and an optional frame-time graph.
- The launcher doesn't check for updates (this fork doesn't update itself).
