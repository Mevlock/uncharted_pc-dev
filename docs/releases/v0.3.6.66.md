**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. Everything in 0.3.6.65 plus the fix below.

**Installing:** the launcher of 0.3.6.30 or newer offers this update itself; or unpack into a new folder and start `Uncharted.exe`.

> **A big thank you to [antikmewzik](https://github.com/antikmewzik)** for his keyboard, mouse and controller work
> ([uncharted_pc_controls_qol](https://github.com/antikmewzik/uncharted_pc_controls_qol)): the button prompts, the mouse in
> the menus, the Keyboard / Mouse menu row and the menu cursor of all three games are built on his code and research.

Shaders prepared with 0.3.6.65 stay valid: no new preparation after this update. The game itself is unchanged.

## Launcher
- **Play works again.** In 0.3.6.65 the launcher's **Play** button, and a double click on a game, did nothing: the
  launcher stopped while hiding the new **Open log folder** button before the start. Sorry about that. Starting a game
  with `Uncharted.exe --play` (front ends such as Playnite) was not affected.
