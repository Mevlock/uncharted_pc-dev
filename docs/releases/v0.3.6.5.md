**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. This is SuperMedo's 0.3.6 plus this fork's changes; everything in 0.3.6.4 plus the list below.

**Installing:** unpack into a new folder and start `Uncharted.exe`. Your launcher settings carry over, but saves live in each install's own `user\savedata` folder: copy that folder over from your previous install, or set **Saves folder** in the launcher to it.

## New in 0.3.6.5
- **Fixed a video memory leak with FSR 3 Frame Generation** (all three games). Every frame, the FSR library allocated a small buffer and descriptors that were never freed: video memory grew by about 6 GB in 40 seconds until the game stopped with "out of device memory". It now stays flat, and the frame rate is a little higher too (the texture cache no longer runs short of memory). DLSS Frame Generation was not affected.
- **Uncharted 2: turret sections no longer blur everything** (from spacepepperoni's Linux fork, upstream PR #381). The turret view's depth of field reads a focus distance the GPU works out; it never reached the game, so the focus stayed close up. Tiny render targets like that one are now copied back to the game.

## Tested for this release
Automated runs on an RTX 50 card at 3440×1440, in all three games:
- Frame generation: FSR 3 and DLSS 2×, 3×, 4×, at Native and Quality, all working at their exact multipliers.
- Anti-aliasing: Off, TAA, FSR 3.1, FSR 4 and DLSS.
- Frame rate limit 120 with DLSS 2×: 60 game frames shown at 120, evenly paced.
- 20 minutes of Uncharted 3 at Quality with DLSS Frame Generation: no crash, no memory growth.
- A clean install from the previous release zip.

## Known issues
- FSR 4 can freeze the game for several seconds the first time it starts (setting itself up); later starts are normal.
- Uncharted 1 and 2 with Quality, Balanced or Performance, and Uncharted 2 at native resolution, work in the opening areas but haven't had a full playthrough (cutscene videos, HUD, menus).
- Ultrawide: short scripted scenes can still switch to 16:9 by mistake; **Always fill** avoids it.
- DLSS Frame Generation goes up to 4×.
