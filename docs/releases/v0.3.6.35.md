**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. Everything in 0.3.6.34 plus the changes below.

**Installing:** the launcher of 0.3.6.30 or newer offers this update itself; or unpack into a new folder and start `Uncharted.exe`.

## New
- **Cheats page** in the launcher: Infinite Health and Infinite Ammo, set for each game separately (by saulo benigno, from SuperMedo's port). They work on every game version the port knows; Infinite Ammo in Uncharted 3 is still being checked.
- **New look for the launcher**, by SuperMedo: warm colours, a compass emblem, and new cover pictures and a map banner drawn for the port (no official art).
- **Change image:** hover a game's cover, or click the banner, to use your own picture, with zoom and position (by poncho-ajmv, from SuperMedo's port). Your picture stays where it is; Restore brings back the original.

## Fixed
- **Shader preparation on every known version of the game.** 0.3.6.34 switched it off on version 1.00; it is back:
  - US 1.00 and EU 1.00 (including EU dumps whose files were never updated, even when they say 1.02),
  - US 1.02, EU 1.02 and EU/Russian (CUSA02344).

  Each one now prepares from a list of where its shaders are, so the first start does not search all the game files. A version the port does not know still skips the preparation (shaders are then built while you play).
- **Game version check:** the launcher now recognises the game by the code it runs instead of the whole file, so dumps made with other tools are recognised too.

## For bug reports
The first lines of `last_run.log` now also say which build of the game code you have (1.00 or 1.02) and which shader list it uses.
