**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. Everything in 0.3.6.62 (the 0.3.6.58 base) plus the changes below.

**Installing:** the launcher of 0.3.6.30 or newer offers this update itself; or unpack into a new folder and start `Uncharted.exe`.

> **A big thank you to [antikmewzik](https://github.com/antikmewzik)** for his keyboard, mouse and controller work
> ([uncharted_pc_controls_qol](https://github.com/antikmewzik/uncharted_pc_controls_qol)): the button prompts, the mouse in
> the menus, the Keyboard / Mouse menu row and the menu cursor of all three games are built on his code and research.

These changes come back from 0.3.6.59 and 0.3.6.60. None of them touches frame timing or performance.

## Fixes
- **Uncharted 3: no more one-frame camera snaps** at the end of animated camera moves (for example on the desert horse
  ride). This is a bug of the original game, on the PS4 too.

## Launcher
- **Collection menu button** on the Play page (next to Add to Steam and Desktop shortcut): starts the collection's own
  game menu.
- **Portable option** on the Game page: "Portable: keep the launcher settings in this folder".
- **Mouse in the collection menu's game carousel:** a click on its left or right side turns it.
