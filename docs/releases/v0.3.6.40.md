**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. Everything in 0.3.6.39 plus the change below.

**Installing:** the launcher of 0.3.6.30 or newer offers this update itself; or unpack into a new folder and start `Uncharted.exe`.

## Changed
- **Shader preparation for other regions' releases:** copies of the collection whose game code the port knows but whose release it has no shader index for, such as the Spanish release (CUSA02826), now get shader preparation instead of having it switched off. The first start reads the game files once to find the shaders (a few minutes, longer on a hard drive) and keeps the result; later starts prepare as usual. Before, these copies compiled shaders during play, with more stutter the first time each area loaded.
