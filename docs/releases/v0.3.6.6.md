**Unofficial fork build.** The official port is [SuperMedo's uncharted_pc](https://github.com/Supermedo/uncharted_pc); please don't report problems with this build to him. This is SuperMedo's 0.3.6 plus this fork's changes; everything in 0.3.6.5 plus the list below.

**Installing:** unpack into a new folder and start `Uncharted.exe`. Your launcher settings carry over, but saves live in each install's own `user\savedata` folder: copy that folder over from your previous install, or set **Saves folder** in the launcher to it.

## New in 0.3.6.6
- **Uncharted 1 and 2 at Native: anti-aliasing works again.** Since these games got native resolution, Native sent the anti-aliasing to an older path that only works at the games' own 1920×1080, so at any other size DLSS, FSR and TAA silently never ran (only their sub-pixel jitter, which can make the picture shimmer slightly). Now all three games use the same path. **Correction:** the 0.3.6.3 notes said "DLSS is DLAA at Native in every game"; for Uncharted 1 and 2 that was not true until this release. Uncharted 3 and every Quality/Balanced/Performance mode were not affected.
- **Memory leak in GPU command processing fixed** (shadPS4 #5258, via iannitram's upstream PR #387): every nested GPU command buffer the game ran left a little memory behind, about 37 MB a minute, or 2 GB an hour of play.
- The release zip now uses forward slashes in its paths, so unzip tools outside Windows unpack it properly.
- Launcher: the Anti-aliasing explanation mentions FSR 4's one-time pause the first time it starts (the graphics driver prepares it, about 10 seconds; later starts are instant).

## Known issues
- Uncharted 1 and 2 with Quality, Balanced or Performance, and Uncharted 2 at native resolution, work in the opening areas but haven't had a full playthrough (cutscene videos, HUD, menus).
- Ultrawide: short scripted scenes can still switch to 16:9 by mistake; **Always fill** avoids it.
- Rarely, the game froze while exiting after a long session; it hasn't happened again in later 20-minute tests.
- DLSS Frame Generation goes up to 4×.
